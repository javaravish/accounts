Admin & Data Tools

This standalone HTML prototype stores information locally in your browser. It does not send financial data to a server.

For multi-user access, central database, login security, and authoritative audit trails, this prototype would need a backend server.

Formula / source workbook review notes

  • The workbook uses mixed reporting years in titles: some monthly/cashbook titles refer to 2025, while the cumulative DCB sheet says 2026–27 and other reports include 2024–25.
  • Some month sheets contain hard-coded opening balances and transfer values; confirm these before relying on balances.
  • Spreadsheet formula results depend on Excel recalculation. This HTML project recalculates its own entered data and does not import every existing Excel formula automatically.
